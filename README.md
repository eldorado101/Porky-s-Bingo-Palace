Porky's Bingo Wheel is a self-contained Bingo number caller built by Dwight Bedsaul with HTML, CSS, and JavaScript. It features a spinning wheel with 75 standard Bingo balls (B1 through O75), ensures no duplicates are called during a session, and displays the selected number in a large ball at the center of the wheel.
The interface includes a call history log on the right side that updates in real time with color-coded entries matching traditional Bingo letter colors. Users can spin the wheel by clicking the "Spin" button or pressing the spacebar. A fullscreen mode is available via the "Fullscreen" button, and pressing the Esc key exits fullscreen as expected.
The entire application runs from a single HTML file—no external dependencies, internet connection, or installation required. Simply open porkys-bingo-wheel.html in any modern web browser to start playing.
To reset the game and clear the call log, click "Clear Log". The wheel spins for 2 to 4 seconds with 8–12 full rotations for a dramatic, engaging effect. This was a simple, bit fun project by Dwight Bedsaul.
